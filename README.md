# Long Sleepy Story YouTube Automation

An automated pipeline for generating and uploading long-form, atmospheric bedtime sleep stories and relaxing audiobooks.

---

## <a name="privacy"></a> Privacy Policy

**Effective Date:** September 10, 2026

1. **Information Collection & Usage:** This application connects to the YouTube Data API v3 strictly to manage and upload bedtime story videos to the authorized YouTube channel (`@longsleepystory`).
2. **Data Storage:** No personal user data, browsing history, or third-party information is collected, stored, or sold. OAuth credentials and tokens are encrypted and used solely within GitHub Actions for automated video uploads.
3. **Third-Party Services:** This service interacts with the Google YouTube API in compliance with [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy).
4. **Contact:** For questions regarding privacy, contact `teryohana@gmail.com`.
